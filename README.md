# Six Refuses

An interactive, first-principles quantum mechanics lab built around Euler’s
36 officers problem.

The experience moves from the optimal classical near-solution through complex
amplitudes, interference, tensor products, entanglement, and the exact analytic
golden QOLS(6) construction. The 36 states in app/quantum-data.ts are
transcribed from Appendix B of arXiv:2204.06800.

## Run

    npm install
    npm run dev

## Verify

    npm test
    npm run lint
