# Changelog

All notable project changes are documented here.

The format follows Keep a Changelog, and releases use semantic versioning.

## Unreleased

### Changed

- Renamed the public repository to `euler-36-officers-quantum-lab` while keeping
  “Six Refuses” as the app’s short name and “The Impossible Quantum Lab” as its
  editorial title.
- Broadened the audience language to welcome highly curious learners of any age.

## 1.0.1 — 2026-08-07

### Security

- Updated the application and build dependency graph to versions with no known
  vulnerabilities reported by `npm audit` at the time of the update.

### Changed

- Prepared the Vite configuration for its future native configuration loader.
- Kept incompatible TypeScript, ESLint, and Node type-definition major upgrades
  out of routine Dependabot updates until they receive dedicated migrations.

## 1.0.0 — 2026-08-07

### Added

- The complete Six Refuses learning journey.
- Interactive classical 3×3 and optimal near-solution 6×6 parades.
- Amplitude, measurement, relative-phase, and interference experiments.
- Product-state and entanglement comparisons with an idealized CHSH game.
- The exact 36-state Golden QOLS(6) construction.
- Phase-erasure, marginal-scan, golden-ratio, and perfect-tensor inspectors.
- Responsive, keyboard-focusable, reduced-motion-aware visual design.
- Deterministic mathematical invariant tests and continuous integration.
- Open-source governance, scientific provenance, security, and contributor
  documentation.
